# NVVM.jl

Julia wrappers for NVIDIA's libNVVM, which compiles LLVM IR to PTX code or to LTO-IR.


## Installation

libNVVM comes from the same CUDA toolkit as the rest of the CUDA compiler (e.g. `ptxas`):
the one CUDA_Compiler_jll selects based on your driver, or a local toolkit when that JLL is
configured to use one (see CUDA.jl's documentation). Without a driver, select a toolkit with
the `version` preference:

```toml
# LocalPreferences.toml
[CUDA_Compiler_jll]
version = "13.5"
```


## Quick start

Let's start with some IR:

```llvm
target datalayout = "e-p:64:64:64-i1:8:8-i8:8:8-i16:16:16-i32:32:32-i64:64:64-i128:128:128-f32:32:32-f64:64:64-v16:16:16-v32:32:32-v64:64:64-v128:128:128-n16:32:64"
target triple = "nvptx64-nvidia-cuda"

define ptx_kernel void @kernel(ptr %out) {
entry:
    store i32 42, ptr %out
    ret void
}

!nvvmir.version = !{!0}
!0 = !{i32 2, i32 0}
```

With NVVM.jl, you can compile this IR to PTX:

```julia
using NVVM

prog = Program()
add!(prog, ir)
verify(prog; arch=v"10.0")
print(String(compile(prog; arch=v"10.0")))
```

```
//
// Generated by NVIDIA NVVM Compiler
//
// Compiler Build ID: CL-39125733
// Cuda compilation tools, release 13.5, V13.5.37
// Based on NVVM 23.0.0
//

.version 9.5
.target sm_100
.address_size 64

	// .globl	kernel

.visible .entry kernel(
	.param .u64 .ptr .align 1 kernel_param_0
)
{
	.reg .b64 	%rd<3>;

	ld.param.b64 	%rd1, [kernel_param_0];
	cvta.to.global.u64 	%rd2, %rd1;
	st.global.b32 	[%rd2], 42;
	ret;

}
```

Modules can be added as textual IR or as bitcode (e.g. generated by LLVM.jl). For
architectures before Blackwell, libNVVM reads them as LLVM 7 IR unless passed the
`nvvm_latest` option. `NVVM.llvm_version(arch)` returns the LLVM version it reads for an
architecture. `add!` can also downgrade a module to LLVM 7 bitcode first, which it does by
default for textual IR (`downgrade=true`).

Compiler options are passed to `compile` and `verify`, as strings or as keyword arguments:

```julia
compile(prog, ["-arch=compute_90", "-nvvm-latest"])
compile(prog; arch=v"9.0", nvvm_latest=true, debug=true, opt=0, prec_sqrt=false)
```

With `gen_lto=true`, `compile` generates LTO-IR, which nvJitLink links with device code
from other compilers.

libNVVM is thread-safe, as long as each program is only used by one thread at a time.


## Limitations

libNVVM generates code for the latest PTX ISA version it supports, which may be too new for
your driver. For Blackwell and later architectures, the `ptx_version_target` option (e.g.
`ptx_version_target=86` for PTX 8.6) selects an older version.
